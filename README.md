# PRNG-prueba-
Un RNG es un sistema matemático que atraves de un valor inicial o semilla inicial genera números al azar, sabiendo la semilla inicial podemos determinar o predecir los resultados, los casinos online los usan, la semilla inicial puede ser un valor establecido, una contraseña o en casos como la librería RANDOM de python usa Mersenne Twister (MT19937).
